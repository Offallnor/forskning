# Innboks for forskningsartikler

Her laster du opp artikler og rapporter som ikke kunne hentes automatisk.

1. Last ned PDF-en fra lenken i lista over manglende kilder (`mangler.md` i spørsmålsmappen).
2. Dra filen inn på opplastingssiden og trykk «Commit changes». Filnavnet spiller ingen rolle.
3. Etter et par minutter er PDF-en lest inn og slettet. Resultatet står i `logg.md` her.

Kilden finnes ut fra innholdet: DOI på forsiden, ellers tittelen. Er den usikker, legges teksten i `ukjent/`, og den må kobles for hånd. Skannede PDF-er uten tekst kan ikke leses.

Fila og teksten lagres i kildebiblioteket (`forskning/kilder/<id>/`), så neste bruker kan lese kilden.
