# Forskning

Kunnskapsoversikt og løype for spissede forskningsspørsmål om arbeid, velferd, arbeid og helse og integrering. Start i `forskning/VEIVISER.md`. Et nytt spørsmål følger `forskning/LOYPE.md`.

## Fulltekst

Repoet er åpent. Tekstene og PDF-ene fra kildene ligger i det private repoet `Offallnor/forskning-tekst` med de samme stiene, fordi de kan være vernet av opphavsrett. Før du leser kilder eller kjører verktøyene lokalt, klon det private repoet og kopier tekstene inn:

```
git clone https://github.com/Offallnor/forskning-tekst ../forskning-tekst
bash forskning/verktoy/fulltekst.sh hent ../forskning-tekst
```

Uten dette ser verktøyene ingen tekst, og kildene hentes på nytt. Lagre aldri fulltekst, PDF-er eller lange sitater i dette repoet. Korte sitater med side i uttrekk og svar er greit.

## Regler for tekst

Repoet er åpent for alle. Skriv ikke navn på personer, departement eller seksjoner som avsender, bestiller eller eier, verken i filer, commit-meldinger eller jobblogger. Løypa kan brukes av hvem som helst: skriv «bestilleren», ikke hvem bestilleren er eller hvor svaret skal brukes internt. Kildenes eget innhold (forfattere, oppdragsgiver) står som det står.
