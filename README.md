# Forskning

Åpen kunnskapsoversikt over norsk og internasjonal forskning på arbeid, velferd, arbeid og helse og integrering, med en fast løype for å svare på spissede forskningsspørsmål: mandat, søk, kildeutvalg, uttrekk, kontroller og eventuelt statistikk.

- Katalogene hentes hver uke fra Nasjonalt vitenarkiv (Sikt), Kudos (DFØ), Navs tidsskrift Arbeid og velferd og Navs bibliotek. Sammendragene står slik forfatterne skrev dem.
- Svarene ligger i `forskning/sporsmal/<mappe>/svar.md`, med kildeliste og kontroller.
- Fulltekst ligger ikke her. Hver kilde lenker til oppføringen eller adressen teksten ble hentet fra.

Dette er forskningsoppsummeringer, ikke offisielle vurderinger. Estimatene er hentet ut av en KI-modell og kontrollert etter reglene i `forskning/LOYPE.md`.
